# reference/ - not this FYP's contribution

`locator-inspector-plugin-v1.0.2/` (and its `.zip`) is a related QA tool: a web-side version of "verified-unique locators with A-F grading". It is **kept for ideas only**.
Its self-healing serves test suites, not an end user who cannot take over a failed step, so do not present it as part of this project. Nothing in `agent/`, `fyp-mvp/` or `path-b/` depends on it.
